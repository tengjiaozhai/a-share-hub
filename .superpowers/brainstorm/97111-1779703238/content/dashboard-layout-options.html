模拟盘控制台方向选择

目标已经固定：观察列表 + 手动追加代码 + 进阶参数 + 一键跑完 decide / shadow-execute / reconcile。

A

启动卡片式

把“配置参数、选择标的、一键启动”放在首屏顶部，结果区放到下半屏。

适合第一次进入就立刻知道怎么操作，学习成本最低。

代价： 同屏可见的信息密度不高，复盘和监控要往下看。

B

交易工作台式

左侧是观察列表和手动代码，中间是参数面板与运行按钮，右侧是最近结果和链路状态。

更像真正的操作台，配置、启动、看结果都在一屏内完成。

代价： 首屏信息更多，设计不好会显得拥挤。

C

向导步骤式

按“选标的 → 设参数 → 确认执行 → 看结果”四步展开，流程感最强。

适合新手，最不容易误操作。

代价： 与你要的“一键跑完整链路”不完全一致，操作节奏更慢。

推荐

我推荐 B 交易工作台式。

原因很直接：你现在抱怨的不是界面不好看，而是“登进去不知道怎么操作”。B 可以把配置、选择、启动、结果四个动作同时放在一屏里，最符合模拟盘控制台的使用方式。
