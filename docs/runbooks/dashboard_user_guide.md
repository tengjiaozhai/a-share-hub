# A股自动交易系统 - 交易工作台操作说明书

> 本说明书面向完全没有编程经验的用户，手把手教您使用交易工作台。

---

## 一、什么是交易工作台？

交易工作台是您管理股票自动交易的"驾驶舱"。就像开车时您看仪表盘一样，这里显示：
- 系统是否正常运行
- 股票交易的决策过程
- 买卖执行的结果
- 风险控制的状态

## 三、各区域详细说明

### ① 顶部状态条（最上面一行）

这是系统的"健康指示灯"，告诉您系统是否正常运行。

| 位置 | 显示内容 | 含义 | 正常状态 |
|------|----------|------|----------|
| 最左边 | **A-SHARE TRADING HUB** | 系统名称 | 固定显示 |
| 中间偏左 | 🔵 **数据库** | 数据库连接状态 | 绿色圆点 = 正常 |
| 中间 | 🔵 **LLM** | AI决策引擎状态 | 黄色 = 未连接（正常，需要配置） |
| 中间偏右 | 🔵 **行情** | 行情数据源状态 | 黄色 = 未连接（正常，需要配置） |
| 右边 | **SHADOW** 蓝色标签 | 当前运行模式 | SHADOW = 模拟模式（不会真金白银交易） |
| 最右边 | **交易日: 2026-05-26** | 当前交易日期 | 显示今天日期 |

#### 💡 小白须知
- **绿灯** = 正常工作
- **黄灯** = 未连接或等待配置（不用担心）
- **红灯** = 出问题了（需要检查）
- **SHADOW模式** = 只模拟不真买，安全模式

### ② 左侧策略配置面板

这里是您设置交易策略的地方，就像设置汽车的驾驶模式。

#### 📊 初始资金
```
┌─────────────────────┐
│ 初始资金             │
│ ┌─────────────────┐ │
│ │ 1000000         │ │  ← 输入您想投入的总金额（单位：元）
│ └─────────────────┘ │
└─────────────────────┘
```
- **含义**：您打算用多少钱来炒股
- **默认值**：100万（1000000元）
- **怎么改**：直接点击数字修改

#### 📋 监控列表
```
┌─────────────────────┐
│ 监控列表             │
│ ┌──────┐ ┌──────┐   │
│ │600519│ │000858│   │  ← 您想监控的股票代码
│ │  ×   │ │  ×   │   │  ← 点击×可以删除
│ └──────┘ └──────┘   │
│ ┌─────────────┐ [+] │
│ │输入股票代码  │     │  ← 输入新股票代码，点击+添加
│ └─────────────┘     │
└─────────────────────┘
```
- **含义**：您想让系统关注哪些股票
- **默认股票**：
  - `600519.SH` = 贵州茅台
  - `000858.SZ` = 五粮液
  - `601318.SH` = 中国平安
- **添加股票**：输入代码（如 `000001.SZ`），点击 `+`
- **删除股票**：点击股票标签上的 `×`

#### 💡 股票代码格式
- 上海股票：`6位数.SH`（如 `600519.SH`）
- 深圳股票：`6位数.SZ`（如 `000001.SZ`）

#### 📉 最大持仓比例
```
┌─────────────────────┐
│ 最大持仓比例 (%)     │
│ ┌─────────────────┐ │
│ │ 20              │ │  ← 单只股票最多占总资产的百分比
│ └─────────────────┘ │
└─────────────────────┘
```
- **含义**：单只股票最多买多少比例
- **默认值**：20%（即100万最多买20万的某只股票）
- **为什么重要**：防止"把所有鸡蛋放一个篮子"

#### 🛑 止损阈值
```
┌─────────────────────┐
│ 止损阈值 (%)         │
│ ┌─────────────────┐ │
│ │ 5               │ │  ← 亏损多少就自动卖出
│ └─────────────────┘ │
└─────────────────────┘
```
- **含义**：股票跌了多少百分比就卖出止损
- **默认值**：5%（亏5%就卖）
- **为什么重要**：防止亏损扩大

#### 📊 单日最大亏损
```
┌─────────────────────┐
│ 单日最大亏损 (%)     │
│ ┌─────────────────┐ │
│ │ 3               │ │  ← 当天总亏损达到多少就停止交易
│ └─────────────────┘ │
└─────────────────────┘
```
- **含义**：今天总共亏了多少就停止所有交易
- **默认值**：3%
- **为什么重要**：保护您的资金安全

#### 🤖 决策模式
```
┌─────────────────────┐
│ 决策模式             │
│ ┌─────────────────┐ │
│ │ Mock          ▼ │ │  ← 选择AI决策方式
│ └─────────────────┘ │
└─────────────────────┘
```
- **Mock**：使用模拟数据做决策（测试用，不会用真钱）
- **Real**：使用真实AI做决策（开发中，暂不可用）

#### ⚙️ 执行模式
```
┌─────────────────────┐
│ 执行模式             │
│ ┌─────────────────┐ │
│ │ Full          ▼ │ │  ← 选择执行范围
│ └─────────────────┘ │
└─────────────────────┘ │
```
- **Full**：完整执行（决策→下单→成交→对账）
- **Decision Only**：只做决策，不下单

#### ▶️ 运行一轮按钮
```
┌─────────────────────┐
│                     │
│     [运行一轮]      │  ← 点击开始一轮交易决策
│                     │
└─────────────────────┘
```
- **点击后**：系统会自动完成一轮交易决策
- **运行中**：按钮会变成"运行中..."，请等待
- **完成后**：中间区域会显示决策结果

### ③ 中央运行时间线

这是最重要的区域，显示每一轮交易决策的完整过程。

#### 标题栏
```
┌─────────────────────────────────────────────────────────────┐
│ ▸ 本轮运行时间线                              [IDLE/COMPLETED] │
└─────────────────────────────────────────────────────────────┘
```
- **IDLE**：空闲状态，还没有运行
- **RUNNING**：正在运行中
- **COMPLETED**：运行完成

#### 时间线步骤

运行后会显示4个步骤，像时间轴一样排列：

```
┌─────────────────────────────────────────────────────────────┐
│ 决策      10:15:13                                           │
│ ┌──────┐ ┌──────┐ ┌──────┐                                  │
│ │600519│ │000858│ │601318│   ← 系统对每只股票做出的决策      │
│ │ BUY  │ │ BUY  │ │ BUY  │   ← BUY=买入，SELL=卖出          │
│ │ 80%  │ │ 80%  │ │ 80%  │   ← 置信度（越接近100%越确定）    │
│ └──────┘ └──────┘ └──────┘                                  │
├─────────────────────────────────────────────────────────────┤
│ 目标仓位  10:15:14                                           │
│ ┌──────┐ ┌──────┐ ┌──────┐                                  │
│ │600519│ │000858│ │601318│   ← 每只股票计划买多少钱          │
│ │¥100000│ │¥100000│ │¥100000│                                │
│ └──────┘ └──────┘ └──────┘                                  │
├─────────────────────────────────────────────────────────────┤
│ 执行      10:15:16                                           │
│ ┌──────┐ ┌──────┐ ┌──────┐                                  │
│ │600519│ │000858│ │601318│   ← 实际下单结果                  │
│ │BUY 100│ │BUY 100│ │BUY 100│                                │
│ │FILLED │ │FILLED │ │FILLED │  ← FILLED=已成交               │
│ └──────┘ └──────┘ └──────┘                                  │
```

#### 💡 每个步骤的含义

| 步骤 | 名称 | 做了什么 |

| **决策** | AI分析 | 系统分析每只股票，决定买还是卖 |
| **目标仓位** | 计划 | 计算每只股票买多少钱 |
| **执行** | 下单 | 实际提交买卖订单 |
| **对账** | 核对 | 检查订单是否正确执行 |

## 四、新手操作流程

### 第一步：查看系统状态
1. 打开浏览器，访问 `http://127.0.0.1:8010/dashboard`
2. 看顶部状态条，确认数据库显示绿灯
3. 确认模式显示 "SHADOW"（模拟模式）

### 第二步：设置监控股票
1. 在左侧找到"监控列表"
2. 删除不想监控的股票（点击×）
3. 添加想监控的股票（输入代码，点击+）

### 第三步：设置风险参数
1. 设置"初始资金"（建议先用默认的100万）
2. 设置"最大持仓比例"（建议20%）
3. 设置"止损阈值"（建议5%）
4. 设置"单日最大亏损"（建议3%）

### 第四步：运行一轮
1. 点击左侧的 **[运行一轮]** 按钮
2. 等待按钮变成"运行中..."
3. 等待按钮变回"运行一轮"
4. 查看中央时间线的决策结果

### 第五步：查看结果
1. 看中央时间线，了解AI做了什么决策
2. 看底部历史，查看详细记录
3. 看右侧风控，确认没有异常

## 五、常见问题

### Q1: 为什么LLM和行情显示黄灯？
**A**: 这是正常的。系统默认使用Mock模式，不需要连接真实的AI和行情数据源。

### Q2: SHADOW模式是什么意思？
**A**: SHADOW = 影子模式，只模拟交易，不会用真金白银。这是安全的测试模式。

### Q3: 点击"运行一轮"后没反应？
**A**: 
- 检查按钮是否变成"运行中..."
- 如果没有，可能是Kill Switch被激活了（看右侧按钮是否红色）
- 等待几秒钟，结果会显示在中央时间线

### Q4: 为什么决策都是BUY（买入）？
**A**: 因为现在用的是Mock模式，系统默认生成买入决策。接入真实AI后会有不同决策。

### Q5: Kill Switch什么时候用？
**A**: 
- 发现系统异常时
- 想紧急停止所有交易时
- 测试完想重置时

### Q6: 数据会保存吗？
**A**: 是的，所有决策、订单、目标仓位都会保存在数据库中，刷新页面后仍然可以看到。

## 六、注意事项

1. **模拟模式安全**：默认是SHADOW模式，不会真金白银交易
2. **先测试再实盘**：务必先用模拟模式测试多次
3. **设置止损**：一定要设置止损阈值，保护资金
4. **不要频繁运行**：每次运行间隔建议至少1分钟
5. **关注告警**：看到红色告警要及时处理

## 行情接口

- `GET /api/v1/market/stocks?query=五粮&exchange=SZ&limit=20`
  - 返回字段：`symbol`、`code`、`name`、`exchange`
- `GET /api/v1/market/quote?symbol=000858.SZ`
  - 返回字段：`symbol`、`timestamp`、`open`、`high`、`low`、`close`、`volume`、`amount`

## 错误语义

- `404 quote symbol not found: 999999.SH`
  - 说明 symbol 不在 AkShare 股票池内
- `503 quote upstream unavailable: ...`
  - 说明股票池存在该 symbol，但实时行情上游暂时不可用或熔断已打开
