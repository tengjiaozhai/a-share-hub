# A股自动交易系统 SOP

这份说明是给新手看的，目标只有一个：让你能稳定地打开工作台、跑一轮模拟交易、看懂结果，并知道出问题时先检查什么。

## 先记住三件事

1. `影子模式` 是系统总开关。当前项目默认就是影子模式，意思是全流程只做模拟和回写，不会走真实交易通道。
2. `决策模式` 只决定“怎么出建议”。`Mock` 是本地假决策，`Real` 是调用 DeepSeek 生成真实决策文本。
3. `执行模式` 只决定“要不要继续走到订单”。`完整链路` 会跑到对账，`仅决策` 只停在建议阶段。

> 重要：`Real` 不等于真实下单。只要还在 `影子模式`，系统就仍然是安全模拟。

## 推荐你怎么开始

第一次使用时，建议按这个顺序：

1. 先用 `Mock + 完整链路` 跑通一轮。
2. 确认中间链路、右侧风控、底部历史都正常显示。
3. 再切到 `Real + 完整链路`，看 DeepSeek 的建议是否正常返回。
4. 只有当你已经看懂页面结果后，再考虑是否切到 `仅决策` 做对比。

## 启动后端

在仓库根目录执行：

```bash
/opt/anaconda3/envs/py311/bin/python3 -m src.main serve
```

启动后，默认访问：

```text
http://localhost:8000/dashboard
```

如果页面打不开，先检查后端是否还在运行，再检查 `.env` 里的数据库和 LLM 配置。

## 页面怎么读

页面从上到下、从左到右看：

1. 顶部状态条：看系统是否处于 `影子模式`，以及数据库、LLM、行情是否正常。
2. 左侧策略配置：改资金、观察列表、单票仓位、止损阈值、决策模式和执行模式。
3. 中间本轮运行：看这次运行有没有经过 `决策 -> 目标仓位 -> 执行 -> 对账`。
4. 右侧风控状态：看当日盈亏、持仓集中度、活跃目标仓位、未完成订单。
5. 底部历史：看最近决策、最近订单、当前目标仓位和异常事件。

## 正常操作步骤

### 1. 打开工作台

浏览器访问：

```text
http://localhost:8000/dashboard
```

### 2. 先确认安全状态

看右上和顶部状态：

- 顶部应显示 `影子模式`
- `KILL SWITCH` 不应处于激活状态
- 数据库、LLM、行情最好都正常

### 3. 填策略参数

左侧一般只需要看这几个：

- `模拟总资金`
- `观察列表`
- `单票最大仓位 (%)`
- `止损阈值 (%)`
- `单日最大亏损 (%)`

新手先不要改太多，默认值已经能跑。

### 4. 选决策模式

| 选项 | 含义 | 适合什么时候用 |
|---|---|---|
| `Mock (模拟)` | 本地固定规则出建议 | 第一次跑、排查前端链路 |
| `Real (实盘决策)` | 调 DeepSeek 生成建议 | 你想验证真实模型效果时 |

### 5. 选执行模式

| 选项 | 含义 | 适合什么时候用 |
|---|---|---|
| `完整链路` | 决策、目标仓位、执行、对账全部跑完 | 默认推荐 |
| `仅决策` | 只生成建议，不继续执行 | 想先看建议，不想看订单时 |

### 6. 点击运行

点击左侧的 `运行一轮模拟交易`。

运行成功后，中间区域应该依次出现：

1. `决策`
2. `目标仓位`
3. `执行`
4. `对账`

如果你选的是 `仅决策`，那就会在对账前停住，并显示“仅决策模式，跳过执行”。

## 你应该看到什么算成功

### 跑 Mock 时

- 决策表会出现固定的 `BUY / HOLD / SELL`
- 右侧风控会显示当日盈亏、集中度、活跃目标仓位
- 底部历史会新增一条决策和对应记录

### 跑 Real 时

- 决策结果会来自 DeepSeek
- 如果一切正常，中间链路仍然会继续走到执行和对账
- 如果模型或接口有问题，决策理由里会出现 `LLM call failed...`

## 这次已经修好的 400 问题

如果你之前看到过 `LLM call failed: 400 Bad Request`，现在应该先检查这几项：

1. `.env` 里的模型名是否是 `deepseek-v4-pro`
2. 后端是否已经重启
3. DeepSeek API Key 是否还有效
4. 网络是否能访问 `https://api.deepseek.com`

当前这版代码已经把模型名统一成 DeepSeek 官方要求的 API ID，并补了 JSON 输出请求格式，所以 `Real` 模式不应该再因为这个点直接 400。

## 常见问题

### 1. 页面能打开，但一运行就报错

优先看底部 `异常事件` 和中间步骤里的失败原因。

### 2. 右侧盈亏不对

先确认你是不是刚跑完一轮新的对账；如果没有新运行，右侧显示的是上一次的结果。

### 3. `KILL SWITCH` 被激活了

这会阻断交易动作。先解除它，再重新跑一轮。

### 4. 想先练习，不想看真实模型

直接用 `Mock + 完整链路`。这是最适合新手的起点。

## 实时行情搜索

点击顶部 `实时行情` 标签页，可以搜索股票并查看实时行情。

### 搜索 A 股

1. 在搜索栏左侧下拉框选择 `A 股`
2. 输入股票代码（如 `600519`）或名称（如 `贵州茅台`）
3. 点击 `搜索` 按钮或按回车
4. 表格会显示搜索结果的实时行情

### 搜索美股

1. 在搜索栏左侧下拉框选择 `美股`
2. 输入股票代码（如 `AAPL`）或指数代码（如 `NDQ`）
3. 点击 `搜索` 按钮或按回车
4. 表格会显示搜索结果的实时行情

**支持的美股：**
- 30 只知名美股（苹果、微软、谷歌、亚马逊、英伟达、特斯拉等）
- 3 大指数（纳斯达克综合、标普500、道琼斯工业）

**搜索示例：**
- `AAPL` → 苹果公司
- `NDQ` 或 `纳斯达克` → 纳斯达克综合指数
- `SPX` 或 `标普500` → 标普500指数
- `DJI` 或 `道琼斯` → 道琼斯工业指数

### 添加到观察列表

1. 搜索股票后，点击搜索结果中的某一行（会高亮）
2. 点击 `+ 添加到观察列表` 按钮
3. 状态会显示"已添加 XXX 到观察列表"
4. 切换回 `工作台` 标签页，可以看到观察列表已更新

### 返回观察列表

搜索完成后，点击 `返回观察列表` 按钮，会清空搜索状态并显示原观察列表的行情。

## 风控参数说明

左侧策略配置中的风控参数含义：

| 参数 | 默认值 | 含义 |
|------|--------|------|
| 单票最大仓位 | 20% | 单只股票最多占总资金的比例 |
| 止损阈值 | -5% | 单只股票亏损达到此比例时触发止损 |
| 单日最大亏损 | -3% | 当日累计亏损达到此比例时停止新开仓 |

**调整建议：**
- 新手建议使用默认值
- 稳健策略：10% / -3% / -2%
- 激进策略：30% / -7% / -5%

## 最后一条建议

你以后只需要先判断一件事：你是想"看建议"，还是想"看完整流程"。

- 想看建议，选 `Mock` 或 `Real`
- 想看流程，选 `完整链路`
- 想停在建议，不看执行，选 `仅决策`

只要还在 `影子模式`，就把它当成一个可观察、可回放、可排错的安全演练环境。
