# 自动日频模拟交易与连续收益工作台设计

## Summary

把当前“手动点一次跑一次”的模拟交易，改成“按市场自动日频运行 + 手动沙盒试跑并存”的单一路径设计。A 股和美股各自独立账户、独立交易日历、独立收益曲线；手动试跑只写沙盒账户，不影响自动业绩。页面默认围绕 `auto` 账户展示连续净值、区间表现对比和今日自动运行状态。

第一版默认口径：

- A 股和美股都支持，但各自按本市场开盘前时点自动运行
- 自动运行内置在 FastAPI 进程中
- 明确假设单实例运行自动任务
- 成交价按前收盘价
- 提醒只做站内提醒
- “历史对比”统一命名为 `区间表现对比`
- 上线时补近 30 个交易日的历史结果

## Key Changes

### 1. 运行与调度

- 在 FastAPI 启动流程注册两个日频任务：A 股开盘前任务、美股开盘前任务。
- 每个任务先判断本市场是否为交易日，再检查是否已存在 `market + trade_date + source=auto` 的成功运行，避免重复执行。
- 自动任务与手动试跑共用同一套决策与纸面执行逻辑，但必须显式区分 `run_source`：`auto`、`manual`、`backfill`。
- 自动任务失败时记录失败原因、失败阶段和重试建议，但第一版不做自动重试编排。
- 启动后若发现自动账户没有近 30 个交易日的净值快照，则触发一次受控 backfill，补最近 30 个交易日。

### 2. 账本与权威数据

- 新建日频纸面账本作为业绩唯一权威，不再让现有 `account_snapshots` 直接承担长期收益展示。
- 账本实体固定为：
  - `paper_accounts`：按 `market + account_kind` 唯一，`account_kind` 只有 `auto` 和 `manual`
  - `paper_runs`：每次运行一条，含市场、交易日、来源、状态、参数快照、观察列表快照、失败原因
  - `paper_positions`：当前持仓，按账户维度维护
  - `paper_fills`：模拟成交明细，成交价固定按前收盘价
  - `paper_nav_daily`：每日一条净值快照，作为累计曲线和区间表现对比唯一来源
- 现有 `decision_runs`、`target_positions`、`execution_orders`、`broker_events` 继续保留为执行审计链路，但要能关联到 `paper_run_id`。
- `auto` 与 `manual` 账户完全隔离：
  - 自动任务只读写 `auto` 账户
  - `POST /api/v1/dashboard/run` 改为明确只作用于 `manual` 账户
  - 手动试跑不得改写 `auto` 账户持仓、净值、区间统计或提醒状态

### 3. 页面与接口

- 工作台默认展示 `auto` 账户视角，`manual` 作为手动调试沙盒保留。
- 左侧：
  - 保留市场、资金、观察列表、风控参数
  - 按钮文案改为 `手动试跑`
- 中间：
  - 原 `本轮运行` 上方改为 `今日自动运行状态`
  - 新增 `累计净值曲线`
- 右侧：
  - 展示 `今日收益`、`近30日收益`、`近30日最大回撤`、`下次运行时间`
  - 站内提醒只基于 `auto` 账户，状态固定为 `今日未跑 / 运行失败 / 观察列表为空 / 补算未完成`
- 底部：
  - `区间表现对比`：固定 `7天 / 30天 / 90天 / 年初至今`
  - `最近自动运行记录`
  - `最近手动试跑记录`
  - `异常事件`
- `GET /api/v1/dashboard/workbench` 扩展为返回：
  - `automation`: 今日状态、最后一次自动运行、下一次运行时间、补算状态
  - `performance`: 曲线点、区间表现、当前账户净值摘要
  - `manual_sandbox`: 最近一次手动试跑摘要
- 不新增外部提醒接口；第一版不做企业微信、Telegram 或邮件推送。

## Test Plan

- 调度正确性：
  - A 股和美股各自在本市场交易日只自动运行一次
  - 周末和休市日不会生成 `auto` 运行和净值快照
  - 单实例重启后不会因重复注册导致重复跑单
- 账本隔离：
  - 手动试跑只影响 `manual` 账户
  - 自动运行只影响 `auto` 账户
  - 自动收益曲线与区间表现不受手动试跑污染
- 收益与历史：
  - backfill 能补近 30 个交易日并生成连续 `paper_nav_daily`
  - `7天 / 30天 / 90天 / 年初至今` 指标均从 `paper_nav_daily` 计算
  - 前收盘价成交规则在 A 股和美股都能稳定复现
- UI 与提醒：
  - 工作台能正确显示 `已运行 / 未运行 / 失败 / 补算中`
  - 自动失败、观察列表为空、补算未完成时出现站内提醒
  - 页面默认显示 `auto` 账户，手动试跑结果单独可见
- 回归：
  - 现有手动运行、最近决策、最近订单、回测入口仍可用
  - 现有市场切换和观察列表保存逻辑继续工作

## Assumptions

- 第一版只支持单个 FastAPI 实例负责自动调度；多实例抢占和分布式锁不在范围内。
- 自动运行时点按市场本地时区和交易日历计算；美股需正确处理夏令时。
- 第一版不做用户自定义运行时间，默认固定为各市场开盘前。
- 第一版不做外部消息推送，站内提醒就是权威提醒。
- 第一版补近 30 个交易日，不补 90 天。
- `区间表现对比` 是正式文案，替代更模糊的“历史对比”。
