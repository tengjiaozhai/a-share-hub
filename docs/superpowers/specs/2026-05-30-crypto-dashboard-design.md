# Crypto Hub 策略监控仪表盘设计文档

> 生成日期：2026-05-30
> 版本：1.0

---

## 1. 项目概述

### 1.1 项目目标

为crypto-hub模块添加策略监控仪表盘，提供Web界面显示技术指标、交易信号、持仓和订单信息。

### 1.2 核心需求

- 策略监控面板
- Web页面形式
- 显示技术指标、交易信号、持仓、订单

### 1.3 成功标准

1. 仪表盘可以正常访问
2. 所有数据正确显示
3. 数据实时更新
4. 界面美观易用

---

## 2. 架构设计

### 2.1 目录结构

```
crypto-hub/src/
├── api/
│   ├── __init__.py
│   ├── routes_dashboard.py  # 仪表盘API路由
│   └── routes_strategy.py   # 策略API路由
├── templates/
│   ├── base.html           # 基础模板
│   ├── dashboard.html      # 仪表盘页面
│   └── components/         # 可复用组件
└── static/
    ├── css/
    └── js/
```

### 2.2 技术栈

- **后端**：FastAPI + Jinja2模板引擎
- **前端**：HTML + CSS + JavaScript
- **数据**：调用现有API获取数据

### 2.3 模块关系

- 仪表盘模块调用现有的BinanceProvider、OrderManager等模块
- 通过API获取数据，前端通过AJAX调用后端API
- 数据实时更新（每5-10秒刷新）

---

## 3. API设计

### 3.1 新增API端点

| 端点 | 方法 | 功能 |
|------|------|------|
| `/dashboard` | GET | 仪表盘页面 |
| `/api/dashboard/status` | GET | 系统状态 |
| `/api/dashboard/balance` | GET | 账户余额 |
| `/api/dashboard/positions` | GET | 当前持仓 |
| `/api/dashboard/orders` | GET | 订单列表 |
| `/api/dashboard/signals` | GET | 交易信号 |
| `/api/dashboard/indicators/{symbol}` | GET | 技术指标 |

### 3.2 API响应格式

```json
{
  "success": true,
  "data": {...},
  "timestamp": "2026-05-30T10:00:00Z"
}
```

### 3.3 数据流

1. 前端页面加载时调用API获取初始数据
2. 使用JavaScript定时器每5-10秒刷新数据
3. API调用现有的BinanceProvider、OrderManager等模块
4. 返回JSON数据给前端

## 4. 前端设计

### 4.1 页面布局

```
+------------------+
|     导航栏       |
+------------------+
| 系统状态 | 账户  |
+------------------+
| 技术指标 | 信号  |
+------------------+
| 持仓    | 订单  |
+------------------+
```

### 4.2 功能模块

1. **系统状态区** - 显示API连接状态、系统运行时间
2. **账户区** - 显示USDT余额、总资产
3. **技术指标区** - 显示MA、RSI、MACD等指标
4. **信号区** - 显示最新交易信号
5. **持仓区** - 显示当前持仓列表
6. **订单区** - 显示最近订单

### 4.3 样式设计

- 使用现代简洁的UI设计
- 支持深色/浅色主题
- 响应式布局，支持移动端
